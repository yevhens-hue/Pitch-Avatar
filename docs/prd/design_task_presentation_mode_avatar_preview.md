# Задача на дизайн: UI/UX для режима предпросмотра слайдов с Аватаром, Галереи Шаблонов и Управления Доступом

## 1. Контекст и Проблематика (Context & Goals)

### Проблема:

**В Галерее Шаблонов (`/presentation-templates`):**
- На карточках шаблонов отсутствовали наглядные метки типов проектов (`Presentation` vs `Presentation + Avatar`).
- В модальном окне предпросмотра слайдов (`Preview slides`) для аватарных шаблонов не отображались привязанный Аватар, Голос и возможность прослушать сэмпл речи 🎧.
- Пользователь не видел прозрачной связи: клик по `Use template` должен вести в пошаговый процесс создания (`/chat-avatar/create`) с предзаполненными параметрами (аватар, голос, язык, слайды).

**В Суперадминке (Super Admin UI — `/main/presentations` & `/main/add-templates`):**
- В таблицах «Все презентации», разделе «Добавить шаблон» и модале выбора исходного проекта отсутствовали наглядная колонка типов проектов (`Presentation` vs `Presentation + Avatar`) и выпадающий фильтр по типу.
- У суперадмина отсутствовало разделение списка проектов на **My Projects** и **Shared with me** (куда попадают проекты, расшаренные пользователями).

**В Настройках Доступа (`Access Modal`):**
- В попапе прав доступа отсутствовал пункт `Available to Superadmin`. При этом опция `Available to Superadmin` должна быть **строго ограничена** и доступна только аккаунту Content Manager (Наде).

---

### Цель задачи:
Спроектировать целостные визуальные макеты и UI/UX для ключевых зон платформы:
* **1. Галерея Шаблонов (Templates UI):** Метки типов `Presentation` / `Presentation + Avatar`, выпадающий фильтр по типам (`All Types`, `Presentation + AI Avatar`, `AI Avatar Only`, `Presentation`), **единое модальное окно предпросмотра с блоком аватара/голоса и кнопкой прослушивания сэмпла 🎙️/🎧** и бесшовный 4-шаговый переход по `Use template`.
* **2. Суперадминка (Super Admin Presentations, Templates Management & Projects):** 
  * Колонка типа проекта `Presentation` / `Presentation + Avatar` и фильтр по типу в таблицах «Все презентации» (`/main/presentations`), «Добавить шаблон» (`/main/add-templates`) и модале «Исходный проект».
  * Две вкладки списка проектов (`My Projects` и `Shared with me`).
* **3. Пользовательский интерфейс и Права доступа (`Access Modal`):**
  * Добавление пункта `Available to Superadmin` в попап настройки прав доступа **Access Modal**.
  * ⚠️ **Ролевое ограничение (Критично!):** Опция `Available to Superadmin` отображается **только для аккаунта/email Нади (Content Manager — `nadya@pitchavatar.com` / `nadiia@pitchavatar.com`)** и суперадмина. Для обычных пользователей этот пункт скрыт.

## 2. Подробный Обзор Требований к Макетам (Scope of Work)

---

### Блок 1: Галерея Шаблонов (`/presentation-templates`)

#### 1.1. Метки типов проектов на карточках (Project Type Badges)
* **Элементы UI:**
  * На каждой карточке шаблона отображать четкую метку:
    * 📄 **`Presentation`** — стандартный просмотр слайдов без ИИ-аватара.
    * 🤖 **`Presentation + Avatar`** — интерактивная презентация со встроенным аватаром и голосовой озвучкой на слайдах.

#### 1.2. Выпадающее меню фильтрации типов (Project Type Filter Dropdown)
* **Расположение:** В тулбаре Галереи Шаблонов (`/presentation-templates`).
* **Опции выпадающего списка:**
  * `✓ All Types` — все типы шаблонов.
  * `Presentation + AI Avatar` — интерактивные презентации с аватаром.
  * `AI Avatar Only` — шаблоны исключительно аватара.
  * `Presentation` — классические презентационные шаблоны.

#### 1.3. Блок Аватара и Голоса в модальном окне `Preview slides` (`Preview Avatar Presentation`)
При нажатии на кнопку **`Preview slides`** для шаблона типа `Presentation + Avatar` открывается единое модальное окно предпросмотра:
* **Предпросмотр Слайдов:** Главный слайд + горизонтальная полоса миниатюр (filmstrip).
* **Информационный блок Аватара и Голоса:**
  * **Визуализация Аватара:** Фото/аватарка персонажа (круглая рамка с синим акцентным бордером) и имя аватара (например, *"Sara (Product AI Specialist)"*).
  * **Визуализация Голоса и Языка:** Иконка микрофона 🎙️ + название голоса и язык (например, *"Voice: Seraphina Multilingual (English US)"*).
  * 🎧 **Интерактивный плеер / кнопка прослушивания голоса (`Play Voice Sample`):** Кнопка с возможностью прослушать аудио-сэмпл голоса аватара непосредственно в модальном окне.

#### 1.4. Действие кнопки `Use template`
* Кнопки `Use template` на карточке и в модальном окне предпросмотра направляют пользователя в пошаговый визард создания (`/chat-avatar/create`), где предзаполнены:
  1. **Шаг 1: Аватар, голос и язык** из шаблона (пользователь может подкорректировать).
  2. **Шаг 2: Слайды презентации** из шаблона.
  3. **Шаг 3: Инструкции и промпт**.
  4. **Шаг 4: Финальный этап создания**.

### Блок 2: Суперадминка — Таблица презентаций, Раздел «Добавить шаблон», Вкладки и Выбор Исходного Проекта

#### 2.1. Колонка типа проекта и фильтр в таблице «Все презентации» (`/main/presentations`)
* **Колонка `Project Type`:** Бейджи 🤖 `Presentation + Avatar` и 📄 `Presentation`.
* **Фильтр `Project Type Dropdown`:** `All Types`, `Presentation`, `Presentation + Avatar`.

#### 2.2. Раздел «Добавить шаблон» (`/main/add-templates`)
* Таблица управления системными шаблонами содержит колонку типа и фильтр по типу.

#### 2.3. Таблица выбора «Исходного проекта»
* При создании шаблона модал выбора исходного проекта содержит колонку типа проекта, пагинацию и фильтры по типу/языку/статусу.

#### 2.4. Вкладки списка проектов (`My Projects` / `Shared with me`)
* В разделе презентаций суперадмина доступны 2 вкладки:
  * **My Projects** — собственные презентации администратора.
  * **Shared with me** — презентации, расшаренные пользователями (Content Manager) администратору.

---

### Блок 3: Права Доступа (`Access Modal`) — Ограничение для Нади

#### 3.1. Права доступа в попапе Access Modal (`https://app.pitchavatar.com/main/projects` -> Actions -> Access)
* **Выпадающий список Access type:**
  * `Available to me`
  * `Available to company users`
  * `Available to individual users`
  * ⭐️ **`Available to Superadmin`** *(Новый пункт)*

#### 3.2. ⚠️ Ролевое ограничение видимости пункта (Критично!):
* Пункт **`Available to Superadmin`** виден и доступен для выбора **ТОЛЬКО** при входе под учетной записью **Нади (Content Manager — `nadya@pitchavatar.com` / `nadiia@pitchavatar.com`)** или под ролью суперадминистратора.
* Для всех остальных обычных пользователей данный пункт **скрыт из списка**.
