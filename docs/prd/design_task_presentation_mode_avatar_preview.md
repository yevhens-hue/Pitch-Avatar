# Задача на дизайн: Типы презентаций, Галерея Шаблонов, Права Доступности и Обновленный Предпросмотр (Super Admin & User UI)

> **Тип документа:** Design Brief / Task  
> **Продукт:** Pitch-Avatar (Super Admin Panel, Presentation Templates & User Preview Player)  
> **Статус:** Updated & Ready for Design  
> **Дата обновления:** 27 июля 2026 г.  

---

## 1. Контекст и Проблематика (Context & Goals)

### Проблема:
1. **В Галерее Шаблонов (`/presentation-templates`):**
   - На карточках шаблонов отсутствовали наглядные метки типов проектов (`Presentation` vs `Presentation + Avatar`).
   - В модальном окне предпросмотра слайдов (`Preview slides`) для аватартных шаблонов не отображались привязанный Аватар и Голос.
   - Пользователь не видел прозрачной связи: клик по `Use template` должен сразу вести в редактор аватара с предзаполненными параметрами.
2. **В Суперадминке (Super Admin UI & Project Management — `/main/presentations`):**
   - В таблице «Все презентации» и модале выбора исходного проекта отсутствовали наглядная колонка типов проектов (`Presentation` vs `Presentation + Avatar`) и выпадающий фильтр по типу.
   - У суперадмина отсутствовало разделение списка проектов на **My Projects** и **Shared with me** (куда попадают проекты, расшаренные обычными пользователями).
   - В окне настройки доступа (Access Modal) отсутствовал явный вариант `Available to Superadmin`.
3. **В Предпросмотре пользователя и админа (User & Admin Preview Mode):**
   - В предпросмотре зритель/админ видел только слайды без визуализации реального интерактивного опыта (AI-аватар + голосовой ответ + диалоговый чат).
4. **В Модуле Обучения (Coach / Training Mode):**
   - Модуль ранее именовался узко («Sales Coach»), что смущало пользователей, которым нужен коучинг для HR, L&D, онбординга или ситуационных тренингов.

### Цель задачи:
Спроектировать целостные визуальные макеты и UI/UX для 4 ключевых зон платформы:
* **1. Галерея Шаблонов (Templates UI):** Метки типов `Presentation` / `Presentation + Avatar`, карточка аватара/голоса в модале предпросмотра слайдов и бесшовный переход по `Use template`.
* **2. Суперадминка (Super Admin Presentations, Projects & Access):** 
  * Колонка типа проекта `Presentation` / `Presentation + Avatar` и фильтр по типу в таблице «Все презентации» (`/main/presentations`) и модале «Исходный проект».
  * Две вкладки списка проектов (`My Projects` и `Shared with me`).
  * Пункт `Available to Superadmin` в меню прав доступа.
* **3. Предпросмотр (Full User Preview Player):** Совмещенный плеер просмотра **Слайды (70%) + AI-Аватар + Диалоговый чат** с поддержкой переключения Desktop/Mobile.
* **4. Универсальный AI Coach:** Визуальное представление универсального AI-тренажёра для HR, продаж, обучения и ситуационных ролевых игр.

## 2. Подробный Обзор Требований к Макетам (Scope of Work)

---

### Блок 1: Галерея Шаблонов (`/presentation-templates`)

#### 1.1. Метки типов проектов на карточках (Project Type Badges)
* **Элементы UI:**
  * На каждой карточке шаблона отображать четкую метку:
    * 📄 **`Presentation`** — стандартный просмотр слайдов без ИИ-аватара.
    * 🤖 **`Presentation + Avatar`** — интерактивная презентация со встроенным аватаром и голосовой озвучкой на слайдах.

#### 1.2. Карточка Аватара и Голоса в модальном окне `Preview slides`
При нажатии на кнопку **`Preview slides`** для шаблона типа `Presentation + Avatar` открывается модальное окно предпросмотра слайдов:
* **Информационный блок Аватара и Голоса:**
  * **Визуализация Аватара:** Фото/аватарка персонажа (круглая рамка с синим акцентным бордером), имя аватара (например, *"Sara (Product AI Specialist)"* или *"Elena (HR Onboarding Coach)"*).
  * **Визуализация Голоса:** Иконка микрофона 🎙️ + название голоса и язык (например, *"Voice: Seraphina Multilingual (English US)"* или *"Jenny (US English - Warm)"*).

#### 1.3. Действие кнопки `Use template`
* Кнопки `Use template` на карточке и в модальном окне предпросмотра направляют пользователя в редактор создания аватара (`/chat-avatar/create`), где **уже предвыбраны**:
  1. Выбранный аватар из шаблона.
  2. Выбранный голос и язык из шаблона.
  3. Готовая презентация / слайды из шаблона.

---

### Блок 2: Суперадминка — Таблица презентаций, Вкладки и Попап Доступа

#### 2.1. Колонка типа проекта и фильтр в таблице «Все презентации» (`/main/presentations`)
* **Колонка `Тип проекта` (Project Type Column):**
  * В таблице всех презентаций суперадминки должна присутствовать колонка типа с бейджами:
    * 🤖 **`Presentation + Avatar`** (синий/голубой бейдж с иконкой аватара).
    * 📄 **`Presentation`** (серый бейдж с иконкой слайда/документа).
* **Фильтр `Тип проекта` (Project Type Filter Dropdown):**
  * В верхней панели фильтров таблицы отображать выпадающее меню выбора типа: `Все типы`, `Presentation`, `Presentation + Avatar`.

#### 2.2. Таблица выбора «Исходного проекта» (Source Project Modal)
* При выборе исходного проекта для создания шаблонов отображается таблица с сайдбаром *"Исходный проект / Настройте шаблон и выберите проект..."*:
  * Включает колонку **`Тип проекта`** (`Presentation` vs `Presentation + Avatar`).
  * Включает выпадающий фильтр по типу проекта (`Все типы`, `Presentation`, `Presentation + Avatar`), языку и статусу.
  * Пагинацию *"5 на странице / всего N"*.

#### 2.3. Вкладки списка проектов (My Projects / Shared with me)
* **Лейаут таблицы Все презентации / All projects:**
  * Две переключаемые вкладки:
    1. **`My Projects`** — собственные презентации пользователя / суперадмина.
    2. **`Shared with me`** — проекты, расшаренные обычными пользователями администратору (с правами доступа `Available to Superadmin`, `company`, `individual` или отмеченные флагом `isShared`).

#### 2.4. Настройка прав доступа (Access Modal Popup)
* **Элементы попапа:**
  * В выпадающем списке `Access type *` добавить 4-й пункт:
    * `Available to me`
    * `Available to company users`
    * `Available to individual users`
    * ⭐️ **`Available to Superadmin`** (новый пункт)

### Блок 3: Пользовательский Предпросмотр (Full Presentation Preview Player)

**Где располагается:** Экран предпросмотра презентации (`/projects/[id]/preview` или кнопка "Preview" в редакторе).

#### 3.1. Единый плеер предпросмотра Chat Presentation
* На экране одновременно отображаются 3 ключевых элемента:
  1. **Слайды презентации (Slide Stage, 70% ширины):** Основная область просмотра слайда.
  2. **AI-Аватар (Avatar Overlay / Widget):** Анимированный говорящий аватар с микро-индикатором речи.
  3. **Интерактивный Чат (AI Chat Panel, 30% ширины):** Окно диалога с вопросами зрителя и ответами ИИ-ассистента, поле ввода и кнопка микрофона.
* **Состояния Аватара:**
  * `Idle` (ожидание вопроса).
  * `Speaking` (озвучка слайда / ответ аватара, волна эквалайзера).
  * `Thinking` (ИИ генерирует ответ, индикатор пульсации).

#### 3.2. Служебная плашка предпросмотра (Control Bar)
* Переключатель устройств: **Desktop View** / **Mobile View** (с фреймом симуляции мобильного экрана).
* Бадж с выбранным Аватаром и Голосом: `[Avatar: Sara | Voice: Jenny (US)]`.
* Кнопки: **"Edit Presentation"** и **"Test AI Response"**.

---

### Блок 4: Универсальный AI Coach / Training Simulator

* **Универсальное позиционирование:** UI/UX модуля проектируется как универсальная платформа обучения (`AI Training Simulator` / `AI Coach`), поддерживающая сценарии:
  * 🤝 **HR & Onboarding** (онбординг новичков, адаптационные регламенты).
  * 🎓 **Knowledge Check / L&D** (аттестации по курсам и инструкциям).
  * 🎭 **Situational Role-Play** (тренировка диалогов со сложными клиентами, кандидатами или сотрудниками).
  * 💼 **Sales Coaching** (отработка возражений и презентация продуктов).
* **Вкладки редактора:**
  * **`Coach Q&A Set`** — редактирование вопросов, привязка к слайдам, загрузка базы знаний.
  * **`Coach Settings`** — формат ответов (текст/голос/выбор слайда), время сессии, Passing Score и параметры обратной связи.
